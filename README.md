# Calculadora Java ☕

Projeto de calculadora desenvolvido em Java para praticar conceitos fundamentais de programação e organização de código.

## Funcionalidades

- Soma, subtração, multiplicação e divisão
- Operações com números decimais
- Menu interativo no terminal
- Validação de opções do menu
- Tratamento de divisão por zero
- Execução contínua até o usuário escolher sair

## Tecnologias utilizadas

- Java (JDK 25)
- IntelliJ IDEA
- Git e GitHub

## Conceitos praticados

Durante o desenvolvimento, trabalhei com métodos, parâmetros, tipos de retorno, `void`, `return`, condicionais, laços `do while`, `Scanner` e reutilização de código.

Também utilizei Git para registrar as etapas de desenvolvimento por meio de commits.

## Como executar

1. Clone o repositório ou baixe o projeto.
2. Abra a pasta no IntelliJ IDEA.
3. Configure um JDK compatível.
4. Execute a classe `Main.java`.
5. Utilize o menu no terminal para escolher a operação desejada.
